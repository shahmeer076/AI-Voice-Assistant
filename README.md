# 🎙️ D-3 AI Voice & Chat Assistant
A high-performance AI-powered Voice and Text Assistant built using **Flask**, **Groq API**, Speech Recognition, and Text-to-Speech (TTS) engine.

---

## ✨ Features
- **⚡ Ultra-Fast Responses:** Powered by **Groq API** for low-latency AI response generation.
- **🎙️ Voice Input & Output:** Integrated Speech Recognition for voice commands and TTS engine for dynamic speech responses.
- **💬 Text Chat Interface:** Flexible interface supporting both text and speech interactions.
- **⚙️ Lightweight Backend:** Built on Flask for fast execution and simple deployments.

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **AI Model:** Groq API (LLaMA-based fast inference)
- **Audio Processing:** `speech_recognition`, `pyttsx3`
- **Configuration:** `python-dotenv`
